CHARITRA
Your private browsing history vault — powered by AES-256 encryption, dressed in Windows Phone Metro style.
Version 1.0  ·  Chrome Extension  ·  Open Source
what CHARITRA does
🛡
Block Domains
Any domain you add is silently wiped from Chrome's browsing history the moment you visit it.
🔒
Encrypted Vault
Blocked visits are saved in an AES-256-GCM encrypted vault. Unreadable without your password — even from the filesystem.
⊞
Bulk Import
Paste a list of domains and block them all in one click. Supports URLs, bare domains, and www variants.
🔍
Advanced Search
Search captured visits by keyword, domain, page title, and date range. Sort and filter however you like.
📊
Analytics
See your top blocked domains, monthly activity heatmap, and hourly browsing patterns.
⏱
Schedule
Set a time window for when the extension should be active. Perfect for focus hours.
🌗
Dark / Light / System Theme
Choose a theme that suits you. System mode follows your OS preference automatically.
🎨
Metro Accent Colors
8 accent colors inspired by the Nokia Lumia palette. Blue, red, cyan, green, purple, orange, teal, pink.
⬇
Export Vault
Export your vault as JSON after re-confirming your password. Keep your own backup.

The UI is built entirely on the Windows Phone / Nokia Lumia Metro design language — flat tiles, pivot navigation, Bebas Neue titles, Segoe UI body text, and the iconic accent color system. The extension popup is 380 × 580 px, and a full-page vault opens in a separate tab for power users.

getting started
1
Set up your vault password
Click the CHARITRA icon in your toolbar. You'll be asked to create a vault password (minimum 6 characters). This password is never stored — only a PBKDF2 hash is kept. Don't forget it.
2
Add domains to block
Type a domain in the "block this site" box on the dashboard and press Enter or click "+ add". Use the Blocked tab for the full domain manager, or click "⊞ bulk add" to paste a list of many domains at once.
3
Browse normally
Visit any blocked domain. CHARITRA silently deletes it from Chrome's history within 1.5 seconds and queues the visit for your encrypted vault. No trace in the browser.
4
Review your vault
Unlock the extension and open the Vault tab, or click ⊞ to open the full vault page. Search by keyword or date range, sort columns, select entries for bulk delete, or export your data.
5
Tune settings
In Settings you can: change your password, pick a theme, pick an accent color, set auto-lock timeout, enable lock-on-blur, set a schedule for when the extension is active, and toggle auto-unlock on correct password entry.
set up a keyboard shortcut
Why set a shortcut?
Chrome extensions can be assigned a custom keyboard shortcut so you can open CHARITRA instantly — no need to find the toolbar icon. You set this yourself in Chrome's extension shortcut manager.
Windows / Linux
Recommended: Ctrl + Shift + H
macOS
Recommended: ⌘ + Shift + H
how to set it
1
Click the button above
It opens chrome://extensions/shortcuts in a new tab — the official Chrome page for managing extension keyboard shortcuts.
2
Find CHARITRA in the list
Scroll to the CHARITRA entry. You'll see "Activate the extension" with an empty shortcut box.
3
Click the pencil icon and press your shortcut
Click the edit (✏) icon next to the shortcut box, then press your desired key combination. Chrome will confirm it's accepted. Avoid keys already used by Chrome (e.g. Ctrl+T, Ctrl+W).
4
Try it out
Press your shortcut from any tab. The CHARITRA popup will open immediately.
security architecture
AES-256-GCM Encryption
All vault data and blocked domain lists are encrypted with AES-256-GCM before being written to Chrome storage. The stored bytes are opaque Base64 — unreadable from DevTools or the filesystem.
PBKDF2 Password Hashing
Your password is run through PBKDF2-SHA256 with 310,000 iterations (OWASP 2023 recommended). Only the derived hash + salt is stored. The password itself never touches storage.
Password Never Stored
The decryption key is derived on-the-fly from your password each time you unlock. When the popup closes, the key is gone. There is no way to decrypt the vault without the correct password.
Shadow Domain List
The background service worker needs to know which domains to block without access to your password. A plaintext shadow copy of domain names only (no URLs, titles, or timestamps) is kept for this purpose.
Session Timeout
Configurable auto-lock after 1–1440 minutes of inactivity. You can also enable lock-on-blur to lock the vault the moment the popup loses focus or you switch windows.
Filesystem Unreadable
Even if someone accesses your Chrome profile folder directly, all they'll find is a blob of AES-GCM ciphertext. Without your password it is computationally infeasible to recover the data.
what to keep in mind

CHARITRA protects your history from casual inspection and filesystem snooping. It is not a replacement for a full disk encryption solution or a privacy-focused browser. Chrome itself (and your OS) still have access to network traffic and open tabs. For maximum privacy combine CHARITRA with a VPN and private DNS.

The extension is fully open source — audit the code at github.com/pramodbeema/CHARITRA.
